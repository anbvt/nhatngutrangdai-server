# Backend Copilot Package

Giải nén các file này vào root repository backend Spring Boot, sau đó mở `COPILOT_BACKEND_PROMPT.md` và gửi nội dung cho Copilot Agent.

## Files
- `BACKEND_REQUIREMENTS.md`: nghiệp vụ, role và phạm vi MVP.
- `BACKEND_ARCHITECTURE.md`: layered architecture và coding standards.
- `DATABASE_DESIGN.md`: mô hình dữ liệu đề xuất.
- `API_CONTRACT.md`: REST API dự kiến.
- `SECURITY_AND_AUTH.md`: authentication, authorization và bảo vệ dữ liệu.
- `BACKEND_ROADMAP.md`: các phase triển khai.
- `COPILOT_BACKEND_PROMPT.md`: prompt khởi động.

**Lưu ý:** Đây là đặc tả khởi đầu. Copilot phải kiểm tra codebase hiện tại, ghi lại giả định và hỏi lại ở các điểm nghiệp vụ chưa chốt. Không xóa code hoặc thay đổi lớn khi chưa được duyệt.
